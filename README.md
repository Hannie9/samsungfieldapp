# Samsung Field Intelligence App

Shop listing & detail demo - Store Profile & Staffing v20

## Features
- Full-width flat Pin-to-pin filters
- Compact competitor driver table
- Sticky detail quick navigation
- Bottom nav Pro flat enterprise design
- Store profile display & staffing management
- Vietnamese language support
- Mobile-first responsive design

## Deployment

This project is deployed on Vercel and can be accessed at:
**[samsungfieldapp.vercel.app](https://samsungfieldapp.vercel.app)**

### Deploy to Vercel

1. Push code to GitHub
2. Import project in [Vercel Dashboard](https://vercel.com)
3. Select GitHub repository
4. Click Deploy

Or use Vercel CLI:
```bash
npm i -g vercel
vercel
```

## Local Development

```bash
# Install dependencies (optional)
npm install

# Start local server
npm run dev

# Open in browser
# http://localhost:3000
```
